# Configuración local

Esta carpeta contiene únicamente ejemplos sin credenciales reales.

Los secretos y parámetros dependientes de la máquina deben inyectarse localmente o desde CI. No añadir contraseñas, tokens, IPs privadas sensibles ni puertos serie personales a estos ejemplos.

Los puertos actuales (`/dev/ttyUSB1`, `COM5` y `COM6`) son valores de desarrollo y no deben convertirse en requisitos de compilación o CI.
